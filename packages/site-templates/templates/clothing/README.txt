Thank you for purchasing Clothing! This file contains a quick
start guide to get you up and running. For full documentation,
open documentation/index.html in your browser.

----------------------------------------------------------------
QUICK START
----------------------------------------------------------------

1. Open any .html file in a modern web browser to preview.
   The homepage is: clothing.html

2. All styles are in: clothing.css
   All scripts are in: clothing.js

3. Replace placeholder images (Unsplash CDN URLs) with your own.
   See documentation/index.html → Images section for details.

4. Customise colours and fonts by editing the CSS variables at
   the top of clothing.css inside the :root { } block.
