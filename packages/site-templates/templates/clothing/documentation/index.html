Introduction

Welcome to Clothing — a premium, fully responsive HTML5 e-commerce template designed for fashion and clothing brands. Built with pure HTML5, CSS3, and vanilla JavaScript (no frameworks, no build tools), it is easy to customise and deploy anywhere.

  • Pure HTML5 / CSS3 / Vanilla JS — zero dependencies
  • Fully responsive — mobile-first, tested at 320px–2560px
  • Dark mode with localStorage persistence
  • Mini cart, wishlist, product filtering, hero slider
  • 12 pages included out of the box

Requirements

This is a static HTML template. No server, database, or build tool is required. You only need:

  • A modern web browser to preview locally
  • A text editor to customise (VS Code, Sublime Text, etc.)
  • A web host or CDN to publish (any static host works — Netlify, Vercel, GitHub Pages, traditional cPanel hosting, etc.)
No Node.js, PHP, WordPress, or database setup is required.

Quick Setup

1. Preview locally

Double-click clothing.html to open it in your browser, or serve the folder with any local server (e.g. VS Code Live Server extension).

2. Customise your brand name

Search for Clothing across all HTML files and replace with your brand name.

3. Swap placeholder images

All images use Unsplash CDN URLs. Replace each src attribute with your own hosted image. See the Images section for details.

4. Add your products

Products are defined in clothing.js in the MH_PRODUCTS and FP_PRODUCTS arrays. See the Products section.

5. Update navigation links

All navigation links in the header are plain <a> tags pointing to the included HTML pages. Update or add pages as needed.

Colours & Theme

All colours are defined as CSS custom properties in the :root block at the very top of clothing.css. Edit these to match your brand.

:root {
  --black:     #111111;   /* primary dark  */
  --white:     #ffffff;   /* primary light */
  --off-white: #f7f7f7;   /* page background */
  --text:      #222222;   /* body text */
  --text-2:    #555555;   /* secondary text */
  --border:    #e5e5e5;   /* dividers */
  --accent:    #e8474a;   /* call-to-action, highlights */
  --accent-hover: #c73b3e;/* CTA hover state */
  --gold:      #e2a03f;   /* star ratings */
  --green:     #2d8c4e;   /* "in stock", success */
}
Change --accent and --accent-hover to instantly re-theme all buttons, links, and highlights across the entire template.

Fonts

The template uses two Google Fonts, loaded via a <link> tag in the <head> of each HTML file:

To change fonts, replace the Google Fonts <link> tag in the HTML head with your preferred font URL, then update the --font and/or --serif variables in clothing.css.

Images

All placeholder images are served from the Unsplash CDN at:

https://images.unsplash.com/photo-{PHOTO_ID}?w={WIDTH}&q=80

The w parameter controls the rendered width and q controls quality (1–100).

Replacing images

Find every src="https://images.unsplash.com/..." in the HTML files and replace with a URL to your own hosted image. For best results, match the recommended dimensions:

Unsplash images are free for commercial use under the Unsplash Licence. No attribution is required, but replacing them with your own product photography will significantly improve conversion rates.

Products

Products are stored as plain JavaScript arrays in clothing.js. There are two arrays:

  • MH_PRODUCTS — "Must Have" / featured section (10 items)
  • FP_PRODUCTS — "Featured Products" carousel (6 items)

Each product object has the following shape:

{
  id:     1,                       // unique number
  name:   'Essential Oversized Hoodie',
  price:  49.99,
  oldPrice: 69.99,                 // optional — shows strikethrough + sale badge
  badge:  'NEW',                   // optional — 'NEW', 'SALE', 'HOT', etc.
  cat:    'sweatshirts',           // category slug (used for tab filtering)
  img:    'https://images.unsplash.com/photo-1576566588028-4147f3842f27?w=420&q=80',
  rating: 4.5,
  reviews: 128,
  sizes:  ['XS','S','M','L','XL']  // optional
}

Add, remove, or edit products in either array. The renderProductCard() function in clothing.js automatically generates the card HTML from each object.

Must Have tabs

The tabs on the "Must Have" section filter MH_PRODUCTS by the cat field. The tab labels and slugs are set in the initMustHave() function. Edit the tabs array there to add or remove tab filters.

Dark Mode

Dark mode is toggled by the moon/sun icon in the header. It works by adding the class dark-mode to the <body> element, which overrides all CSS variables to their dark equivalents. The user's preference is persisted in localStorage under the key cl_dark.

To add dark-mode overrides for any new section you create, add a rule like:

body.dark-mode .my-section {
  background: var(--off-white);
  color: var(--text);
}

Navigation

The desktop navigation is in the .site-nav element inside each page's header. The mobile navigation drawer is generated dynamically by initMobileMenu() in clothing.js.

To add a new nav item:

  1. Add an <a href="yourpage.html">Label</a> inside .site-nav in every HTML file.
  2. Add 'Label' to the array in the initMobileMenu() function in clothing.js, along with its corresponding href.

  <!-- #toast — Notification toast -->
  <script src="../clothing.js"></script>

</html>

JavaScript

All JavaScript lives in clothing.js. It uses no external libraries and requires no transpilation. Key modules (all IIFEs):

FunctionDescription
initAnn()Rotates announcement bar messages; close button
initHeaderScroll()Adds shadow to header on scroll
initSearch()Expands header search bar on click
initHero()Hero slider — auto-advance (5.5s), prev/next, dots
initCopy()Discount code copy-to-clipboard button
initMustHave()Must Have section tab filter + carousel
initFeatured()Featured Products carousel
initReveal()IntersectionObserver scroll-reveal animations
initMobileMenu()Hamburger → slide-in drawer nav
initDarkMode()Dark mode toggle + localStorage persistence
addToCart()Add product to cart, update badge & mini cart
toggleWish()Add/remove product from wishlist
openMiniCart()Slide-in cart sidebar open/close
